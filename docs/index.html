📁
자유로운 폴더 분류
내가 원하는 방식으로 폴더를 만들고 하위 폴더도 자유롭게 구성할 수 있습니다. 어떤 파일 유형이든 한 폴더에 함께 보관 가능합니다.
🔍
빠른 전문 검색
파일 제목은 물론 PDF 내부 텍스트까지 검색합니다. 원하는 내용을 순식간에 찾을 수 있습니다.
🏷️
태그로 가로 분류
폴더와 별개로 태그를 붙여 여러 폴더에 걸친 파일들을 한번에 모아볼 수 있습니다.
🗄️
전용 보관 폴더
볼트 폴더를 지정하면 파일을 자동으로 복사해 안전하게 보관합니다. 원본 파일이 삭제돼도 걱정 없습니다.
⭐
즐겨찾기 & 최근 열람
자주 보는 파일은 즐겨찾기에, 최근 열어본 파일은 자동으로 모아서 빠르게 접근할 수 있습니다.
🔄
자동 업데이트
새 버전이 출시되면 앱 안에서 바로 알림을 받고 업데이트할 수 있습니다. 항상 최신 상태를 유지하세요.
